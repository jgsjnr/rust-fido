📋 Como usar (passo a passo)

Operações executadas no firmware; esta aba orienta e exibe somente o resultado público.

  1. Gerar slot (UP): toque no botão físico para confirmar presença; o firmware cria a chave sob a curva da rede.
  2. Importar envelope (UP+PIN): o envelope AEGN v1 é aberto com a chave vinculada ao PIN; nada é exibido em claro.
  3. Ver endereço (UP): somente o endereço derivado (bech32 / EIP-55 / base58) é listado — nunca o segredo.
  4. Apagar slot (UP+PIN): remove o slot e zera o material com zeroize.

🔒 Escopo e segurança

Storage-only sobre o KeyManager dedicado; envelope AEGN v1 inalterado.
